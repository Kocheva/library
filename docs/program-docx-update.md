# Моя программа — DOCX и печать

В конструкторе появились название, место проведения, дата (для нескольких дней — начало и окончание периода), время начала и окончания. Поля необязательные. Сведения сохраняются в `delai_program_details_v1` в localStorage; прежние подборки и настройки форматов сохраняются без миграции.

Кнопка «Скачать мою программу DOCX» собирает текущую программу на устройстве пользователя. Внешних сервисов и отправки данных нет. Кнопка «Печать / PDF» использует те же сведения, дни и последовательность мероприятий.

## Правила формирования

- Включаются только дни, назначенные выбранным форматам. Каждый выбранный день начинается с новой страницы. Дни идут по номеру, форматы внутри дня — в заданном пользователем порядке.
- Если выбран только один день, дата окончания не используется, даже если она сохранилась от предыдущей программы.
- Для нескольких дней выводится введённый период. Даты возле каждого дня вычисляются только если период содержит ровно столько последовательных календарных дней, сколько выбрано дней программы. В остальных случаях выводятся период и номера дней без предположений о конкретных датах.
- Общий временной интервал выводится в шапке. Время отдельной активности — её начало и окончание, рассчитанное по продолжительности. Одинаковое время у нескольких активностей допускается.
- Название и краткое описание формата берутся из каталога. Незаданные место, время и сведения о ведущем остаются пустыми. Образцы мероприятий и подсказки в квадратных скобках из шаблона удаляются.
- Для новых форматов время и площадка изначально пустые, продолжительность — видимые в конструкторе 60 минут, которые можно изменить или очистить. Старые настройки не заменяются.
- Неверный порядок дат или времени показывает ошибку; введённые сведения сохраняются. После ошибки экспорта можно повторить скачивание.

## Файлы

- `public/prototype/program-export.js` — общая модель, DOCX и представление для печати.
- `public/prototype/materials/docs/program/program-template.docx` — оригинальный пользовательский шаблон.
- `public/prototype/data/program-template.js` — тот же DOCX в Base64 для работы без сервера через `file://`.
- `public/prototype/vendor/jszip-3.10.1.min.js` и лицензия — упаковка DOCX. Модуль и шаблон загружаются только при скачивании.

Сохранены альбомная ориентация A4, три колонки «Время / Место / Программа», оформление и верхний колонтитул шаблона. Увеличены шрифт таблицы и внутренние отступы для читаемости; заголовок таблицы повторяется при переносе на следующую страницу. Пустые поля ведущего можно дописать в Word.

При замене шаблона требуется пересоздать Base64-копию и проверить структуру таблиц в `documentXML()` — произвольный DOCX не является совместимым шаблоном автоматически. Для синхронизации копии из корня репозитория:

```python
from pathlib import Path
import base64
root = Path('public/prototype')
data = base64.b64encode((root / 'materials/docs/program/program-template.docx').read_bytes()).decode('ascii')
(root / 'data/program-template.js').write_text('window.DELAI_PROGRAM_TEMPLATE = "' + data + '";\n', encoding='utf-8')
```

Остальные разделы, данные каталога, документы и выгрузки XLSX не изменены.
