БИБЛИОТЕКА ОРГАНИЗАТОРА ДЕЛАЙ-САММИТА

Запуск
1. Распакуйте архив целиком.
2. Откройте index.html в современном браузере.

Пароль для входа
- Текущий пароль: start
- Чтобы заменить пароль, откройте app.js и найдите строку:
  const SITE_PASSWORD = "start";
- Замените только текст между кавычками и опубликуйте файлы заново.
- После успешного входа пароль повторно не запрашивается до закрытия вкладки/окна браузера.

Важно: это клиентская защита для ограничения обычного доступа. Пароль находится
в коде сайта, поэтому такой способ не подходит для хранения конфиденциальных данных.

Публикация на GitHub Pages
1. Загрузите содержимое этой папки в корень репозитория.
2. В Settings → Pages выберите Deploy from a branch и папку /(root).

Структура
- index.html — интерфейс;
- styles.css — фирменные стили;
- app.js — интерактивная логика;
- data/*.json — нормализованные данные;
- data/library-data.js — те же данные для запуска без локального сервера;
- materials/docs — DOCX-материалы форматов и доступные приложения этапов;
- materials/pdf/formats — PDF чек-листов, сценариев и полных описаний;
- tools/xlsx — конструктор, план, реестр партнёров и бюджет;
- assets/images — фирменная иллюстрация.

Подборка, программа, статусы задач и бюджет сохраняются в localStorage браузера.

Реестр партнёров
- Изначально открывается одна пустая строка, без примеров и поиска.
- Можно добавлять строки, выбирать несколько типов вклада, менять статус
  и независимо отмечать шесть шагов. Все текстовые поля необязательны.
- Ответственный, контакты и комментарии вынесены в отдельные колонки.
- Удаление строки и очистку реестра можно отменить до следующего удаления
  или перезагрузки страницы. Очистка всего реестра требует подтверждения.
- Данные сохраняются в localStorage, ключ delai_partners_v1. Это сохранение
  для одного браузера и адреса сайта, а не личный кабинет. На общем компьютере
  данные доступны другим пользователям того же профиля браузера.
- Очистка данных браузера, смена браузера/устройства/адреса сайта не переносит
  реестр. В режиме инкогнито сохранение временное. Скачивайте резервные XLSX.
- «Скачать мой реестр · XLSX» выгружает только заполненные строки с текущими
  значениями. Галочки: Да/Нет. Типы вклада: список через точку с запятой.
  Статусы и Да/Нет можно выбирать из списков в Excel. Заголовок и первая
  колонка закреплены. XLSX можно редактировать и открыть в Google Таблицах.
- Обратный импорт XLSX в сайт не реализован.
- Google-таблица открывается отдельно как пример заполнения.
- На телефоне каждая строка раскрывается в форму кнопкой «Заполнить / изменить».
- Если браузер не разрешил сохранение, сайт показывает ошибку; скачивание
  введённых данных остаётся доступным. При конфликте двух вкладок данные
  не перезаписываются молча: можно скачать текущие или загрузить сохранённые.
- Логика раздела: partners.js; поля, списки и XLSX: partners-model.js;
  стили: partners.css. Другие разделы не используют эту модель.
- Для экспорта поставляется локальная ExcelJS 4.4.0 (лицензия MIT в vendor).
  Сохраняйте папку vendor целиком при загрузке сайта. Сеть для экспорта
  не требуется после загрузки файлов сайта; данные реестра не отправляются.

Материалы карточек
- Доступные PDF и DOCX показываются отдельными ссылками в одной строке.
- Полное описание хранится в materials/pdf/formats/<папка>/full_description.pdf.
- Ссылка «Материал Центра ГРАНИ» берётся из поля grani_url карточки.
- Если полного PDF пока нет, сохраняется существующая ссылка на Google-документ.
- Пустые разделы и обещания добавить материалы не выводятся.
- При ручном изменении путей обновляйте data/formats.json и formats внутри
  data/library-data.js одинаково: сайт использует последний файл и без сервера.
