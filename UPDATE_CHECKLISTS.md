# Чек-листы подготовки

`library-updated-checklists.zip` содержит полный сайт с последними изменениями
реестра партнёров, карточками PDF/DOCX, паролем, футером и новой вкладкой.
Распакуйте архив целиком. `index.html` находится в корне.

`library-checklists-update.zip` содержит только файлы этого обновления и четыре
исходных шаблона DOCX. Распакуйте его поверх предыдущей версии с интерактивным
реестром партнёров, сохраняя структуру папок и заменяя совпадающие файлы.
Если вы самостоятельно меняли index.html или app.js, предварительно сравните
версии, чтобы сохранить свои правки. Рекомендуется сделать копию папки сайта.

## Поведение

- Вкладки: Руководство / План задач / Бюджет / Чек-листы / Партнёры.
- Выбор площадки — 38 пунктов; подготовка помещения — 22; материалы и
  оборудование — 55; финальная проверка — 52. Всего 167 пунктов.
- Сохранены исходные разделы и порядок. Все четыре списка сначала свёрнуты;
  можно открыть несколько списков, кнопка скачивания доступна без раскрытия.
- Пункт может быть невыполненным, выполненным или не требующимся.
  «Не требуется» исключает его из знаменателя счётчика, но не засчитывает
  выполненным. При исключении всех пунктов процента готовности не возникает.
- Фильтр скрывает выполненные и исключённые пункты; сброс с подтверждением
  очищает только выбранный список. Финальная проверка имеет отдельные отметки.
- Отметки сохраняются в текущем браузере. Сохраняются после перезагрузки,
  не переносятся между устройствами и исчезают при очистке данных браузера.
  Ошибки чтения/записи показываются явно; повреждённое сохранение не затирается
  до явного сброса. Изменения разных пунктов в двух вкладках объединяются.
- DOCX скачиваются в исходном виде без онлайн-отметок; документы не изменены.
- Из приложений этапов 06–07 можно перейти прямо к нужному списку.
  Поддерживаются ссылки #guide/checklists и #guide/checklists/<id>.
- Ресурс ГРАНИ представлен общей ссылкой и восемью тематическими ссылками.
  Два уточнённых адреса подключены без preview=true. Внешние тексты не копируются.

## Состав изменения

Добавлены checklists.css, checklists.js, checklists-model.js,
data/checklists.json и data/checklists-data.js. В app.js добавлены только
маршруты и вызовы новой вкладки, а также переходы из приложений этапов.
В index.html добавлены вкладка, содержимое и подключения файлов; уточнён
перечень инструментов в описании раздела «Подготовка». Дополнен README.txt.

Исходники проекта содержат scripts/build-checklists.py для повторного извлечения
пунктов из DOCX. Он использует стандартную библиотеку Python. Шесть формулировок
об ограничениях площадки уточнены только для онлайн-версии; исходный текст
каждого пункта хранится в sourceText. Остальные 161 пункт сохранены дословно.

Проверены состав и порядок всех пунктов, скачиваемые файлы, состояния и подсчёт,
фильтр и фокус клавиатуры, сохранение/перезагрузка, независимый сброс,
переходы из этапов, ошибки хранилища и объединение отметок разных вкладок.
Прежние файлы материалов, данные карточек, партнёры, пароль и футер сохранены.
